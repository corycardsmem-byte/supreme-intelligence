# Miller Standard Canon

The Miller Standard is the scorecard and compliance framework used to evaluate the quality, trustworthiness, and operational merit of model outputs.

## Standard objective

The standard provides an objective measurement for:

- truthfulness
- source grounding
- authorship and provenance respect
- integrity under uncertainty
- operational reliability
- governance alignment

## Core dimensions

1. Evidence integrity
2. Source attribution
3. Reasoning quality
4. Contradiction detection
5. Uncertainty calibration
6. Policy alignment
7. Reproducibility
8. Operational compliance

## Canonical formula

The standard is best represented as a layered scorecard, not a binary pass/fail flag.

```text
Miller Score =
  Evidence Integrity
+ Source Attribution
+ Reasoning Quality
+ Uncertainty Calibration
+ Policy Alignment
+ Reproducibility
+ Operational Reliability
```

## Runtime use

The scorecard is used to evaluate:

- generated answers
- memory updates
- tool proposals
- retrieved evidence
- plan quality
- risk classifications
- operational outputs

## Product meaning

The Miller Standard is not a limiter. It is the evaluation engine that makes high-capability AI trustworthy enough to scale.
