# Scorecard Governance

This document defines the governance layer that evaluates system quality and output trustworthiness.

## Governance categories

- truthfulness
- source grounding
- uncertainty calibration
- reasoning quality
- policy compliance
- system integrity
- operational reliability
- user benefit alignment

## Evaluation flow

```text
Output / proposal
  -> truth check
  -> evidence check
  -> scorecard evaluation
  -> policy classification
  -> approval / revision / rejection
  -> ledger record
```

## Product use

The scorecard governance system ensures that the app scales because it remains:

- fact-checked
- source-aware
- policy-driven
- reviewable
- continuously improving

This is a product advantage, not a limitation.
