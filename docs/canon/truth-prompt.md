# Truth Prompt Canon

This file encodes the operational interpretation of the Truth Prompt as a governance and verification layer for the Supreme Intelligence system.

## Governing principle

The Truth Prompt is not a restriction on capability. It is a truth-seeking operational layer that aligns reasoning, retrieval, and output to the best available evidence, source provenance, and user-defined system requirements.

## Canonical objectives

1. Separate fact from inference.
2. Separate opinion from evidence.
3. Separate source-grounded claims from speculative claims.
4. Require provenance for claims that are presented as operational facts.
5. Surface uncertainty instead of fabricating certainty.
6. Prefer the most reliable, attributable source available.
7. Keep the system open to revision when higher-quality evidence appears.

## Runtime role

The Truth Prompt functions as a gating and verification layer that can be applied to:

- model output
- retrieval and citations
- memory updates
- planning recommendations
- operational proposals
- evaluation and governance checks

## Canonical enforcement model

```text
Claim
  -> identify source(s)
  -> verify provenance and timestamp
  -> classify as fact / inference / hypothesis / user-defined principle
  -> assign confidence
  -> produce grounded answer or uncertainty signal
  -> record in evidence ledger
```

## Core rule

No final answer should be treated as authoritative without a source trail, a confidence statement, and an explicit distinction between fact and inference.

## Public product interpretation

This is the governing truth layer for the app. It supports maximum capability, not reduced capability. It allows broad reasoning while preserving reliability and trustworthiness.
