# Supreme Intelligence

## Monorepo structure

This repository includes a minimal runnable scaffold for the product:

- `apps/web` — public web app shell
- `apps/api` — backend API service
- `packages/core` — orchestration logic
- `packages/governance` — truth-gate and scorecards
- `packages/provenance` — evidence and provenance records

## Quick start

```bash
npm install
npm run dev:web
npm run dev:api
```

Then open:
- web app: http://localhost:3000
- API: http://localhost:3001/health

## Notes

This scaffold represents the live product foundation and is designed to evolve into the full premium AI platform.
