# Launch Roadmap

## Phase 1 — MVP

Goal: launch a capable AI workspace with governance and provenance built in.

### Deliverables
- web app shell
- authentication
- chat interface
- source-aware retrieval
- citations
- memory layer
- truth-gate evaluation
- scorecard display
- billing and subscriptions
- audit log basics

## Phase 2 — Governed execution

Goal: support controlled actions and tool use.

### Deliverables
- tool adapters
- approval gateways
- authority boundaries
- action classification
- evidence ledger integration
- policy configuration
- team workspaces

## Phase 3 — Enterprise expansion

Goal: enterprise-grade deployment and sovereign governance.

### Deliverables
- org policy packs
- custom scorecards
- enterprise SSO
- deployment options
- compliance controls
- audit export
- API platform

## Phase 4 — Sovereign platform

Goal: durable long-horizon infrastructure.

### Deliverables
- versioned governance registry
- artifact manifests
- model protocol versioning
- archival and recovery
- long-lived provenance storage
- white-label and licensing options

## Launch gate

The product is ship-ready when:
- core features function reliably
- truth and provenance pipeline is stable
- scorecard engine passes regression scenarios
- policy enforcement is validated
- audit logging is complete
- billing and auth are working
- staging-to-production flow is tested
