# MVP Product Backlog

## Objective
Ship a working, public-facing AI product that is source-aware, truth-aware, and monetizable while preserving a solid governance foundation.

## Milestone 1 — Foundation
- repo structure and service boundaries
- app shell and initial routing
- auth and user account scaffolding
- environment and deployment configuration
- logging and observability basics

## Milestone 2 — Core Experience
- chat workspace UI
- conversation history
- user profile and settings
- prompts and saved workflows
- retrieval-backed responses
- citations and source display

## Milestone 3 — Governance and Trust
- truth gate evaluation
- scorecard system
- provenance capture
- evidence ledger records
- uncertainty and confidence display
- review and approval flows for sensitive actions

## Milestone 4 — Monetization and Operations
- subscription plans
- billing integration
- usage billing and limits
- usage analytics
- support and feedback loop
- operational health dashboards

## Milestone 5 — Launch Readiness
- staging environment
- production deployment
- security review
- policy and privacy review
- launch checklist and release gating

## MVP Features
- user authentication
- workspace and chat
- retrieval from corpus
- citations
- memory and profile
- truth-gate output classification
- Miller Standard scorecard display
- audit log
- billing
- admin controls

## Definition of done
- end-to-end user flow works
- citation and provenance are attached to outputs
- truth-gate and scorecard run in production flow
- evidence ledger captures meaningful actions
- app can be deployed to staging and production
- billing works for subscriptions
