# Security and Governance

## Principles
- evidence before claim
- provenance before operational trust
- policy before tool execution
- approval before sensitive actions
- explicit uncertainty before certainty

## Controls
- authentication and session security
- role-based access control
- least privilege for tools and integrations
- model action guardrails
- audit logging
- retention and export controls
- secure secret handling

## Governance runtime
- truth-gate service
- scorecard engine
- authority boundary checks
- approval routing
- policy evaluation and logging

## Runtime rule
Any action beyond simple response generation requires explicit policy validation and recorded approval.
